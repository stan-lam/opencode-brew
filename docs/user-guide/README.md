# OpenCodeBrew User Guide

Welcome to OpenCodeBrew, a modern cross-platform desktop development environment with integrated AI capabilities.

## Applications

OpenCodeBrew includes four integrated applications:

| App | Description |
|-----|-------------|
| [**Launcher**](launcher.md) | Central hub for launching apps and managing settings |
| [**IDE**](ide.md) | Full-featured code editor with AI assistant |
| [**Notes**](notes.md) | AI-powered note-taking and conversation app |
| [**Assistant**](assistant.md) | Automated AI agents with scheduled tasks |

## Quick Start

1. **Launch OpenCodeBrew** - Open the application to see the Launcher hub
2. **Configure AI** - Click the ⚙️ icon to set up your AI provider (Ollama, OpenAI, Anthropic, or GitHub Copilot)
3. **Choose an App** - Click on IDE, Notes, or Assistant to get started

# Launcher

The Launcher is your central hub for accessing all OpenCodeBrew applications and managing global settings.

![Launcher](../screenshots/landing.png)

## Features

### Application Tiles

Click on any tile to launch the corresponding application:

| Tile | Description |
|------|-------------|
| **IDE** | Open the code editor for a project |
| **Notes** | Open the AI-powered notes application |
| **Assistant** | Open the AI agents and automation dashboard |

### Settings

Click the **⚙️** icon in the top-right corner to access global settings:

- **AI Provider** - Choose between Ollama, OpenAI, Anthropic, or Copilot
- **API Keys** - Configure authentication for cloud AI providers
- **Model Selection** - Choose which AI model to use
- **Temperature** - Adjust AI creativity (0 = deterministic, 1 = creative)

### Recent Projects

The Launcher remembers your recent projects and workspaces for quick access.

## Footer Links

- **Version** - Shows the current OpenCodeBrew version
- **GitHub** - Opens the project repository
- **Documentation** - Opens this user guide
